# Visual Archive — Personal Photography

Visual Archive es un proyecto web personal concebido como una galería fotográfica digital: una forma de organizar y presentar fotografías con una experiencia visual cuidada, sin las dinámicas de una red social tradicional.

Desarrollado con Next.js y React, el proyecto explora una galería tipo masonry, visualización de medios y una interfaz minimalista centrada en el contenido.

## Objetivo

Crear un archivo visual personal, responsive y de estética minimalista, donde las fotografías y los videos sean el centro de la experiencia.

## Características del proyecto

- Aplicación basada en Next.js App Router.
- Galería visual con composición tipo masonry.
- Componentes reutilizables para presentar medios.
- Animaciones de interfaz con Framer Motion.
- Soporte para temas mediante next-themes.
- Iconografía con Lucide.
- Base preparada para integración de servicios con Supabase.
- Estructura de tipos, datos y componentes separados.

> El alcance de funciones como estadísticas en tiempo real, almacenamiento remoto o interacción persistente depende de la configuración de servicios y de la implementación activa del proyecto.

## Tecnologías

- Next.js

## Requisitos

- Node.js compatible con la versión de Next.js del proyecto.
- npm.
- Variables de entorno si se utilizan integraciones externas.

## Instalación

```bash
git clone https://github.com/miguelagcz/loquenosalio.git
cd loquenosalio
npm install
npm run dev
```

Abre http://localhost:3000 para revisar la aplicación localmente.

## Variables de entorno

Si habilitas servicios externos, configura sus credenciales en un archivo local como `.env.local`. No subas secretos ni claves privadas al repositorio.

## Qué demuestra

Diseño de una experiencia visual centrada en fotografía, arquitectura de componentes, composición masonry, tipado con TypeScript y organización de una aplicación Next.js en evolución.
